# Fitness Achieve Cloud Video Editor
Open this repository in GitHub Codespaces using Code > Codespaces > Create codespace on main.
The devcontainer provisions Node 22, Python and FFmpeg, and attempts to install local Whisper. Check the terminal logs for failures; do not assume success.
HyperFrames / Herk Edit Kit requires separate upstream review and installation; it is NOT installed by this configuration.
For editing: read MY-PREFERENCES.md, ask the three pre-edit questions, create draft, review, then render final.
Do not commit raw client footage, API keys, credentials or private assets to this public repository. Store source files and exports in appropriate private storage.
Codespaces has storage, compute and retention limits; commit configuration changes to GitHub and back up outputs elsewhere.
